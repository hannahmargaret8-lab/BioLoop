Thank you for your interest in contributing to BioLoop.

Guidelines:

- Open an issue first to discuss larger changes.
- Create a feature branch per change and open a PR against `main`.
- Add tests for new functionality. CI enforces compile checks and pytest.
- Follow the code style: run `black .` and `flake8` before submitting.
- Keep hardware-specific code behind simulation flags or guards so CI can run tests without hardware.
